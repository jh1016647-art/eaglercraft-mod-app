# Eaglercraft Mod App

This is a simple static browser app for managing a themed Eaglercraft mod collection. It includes a starter UI for the following mod ideas:

- Verity Mod
- FNAF Pack
- Curse Steve
- Utility Boost

## Run locally

Open `index.html` directly in a browser, or serve it with a lightweight local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

This project is a front-end starter app for a mod manager UI. It does not ship copyrighted mod assets or game files. It is meant as a clean template you can expand with your own package manifests, mod downloads, or custom launch logic.
